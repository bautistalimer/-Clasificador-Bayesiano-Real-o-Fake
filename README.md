# Clasificador de Noticias Reales y Falsas con Naive Bayes (Python)

Implementación educativa de un **Clasificador Bayesiano Ingenuo (*Naive Bayes*)** programado íntegramente en Python sin utilizar librerías de Machine Learning externas, enfocado en la detección de noticias reales (*real*) frente a noticias falsas (*fake*).

---

## 🎯 Objetivo del Proyecto
Aplicar el Teorema de Bayes y las probabilidades condicionadas con suavización de Laplace sobre titulares de texto para automatizar la tarea de validación de información informativa.

---

## ⚙️ Características Técnicas
* **Desarrollo nativo:** Programado con estructuras de datos estándar de Python (`collections.defaultdict`).
* **Cálculo de probabilidades previas y condicionales:** Determina la frecuencia de aparición de términos lingüísticos asociados a contenidos fidedignos o sensacionalistas.
* **Métricas de evaluación:** Incluye el cálculo de **precisión global (accuracy)** y una **matriz de confusión** para medir el desempeño del modelo.
